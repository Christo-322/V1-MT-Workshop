# C3Pay Money Transfer Open Studio

Design workshop site: Experience → Inspire → Critique → Top critiques → Make → Pitch.

- Live site: https://christo-322.github.io/V1-MT-Workshop/
- Host mode (hide junk critiques, Reset all): https://christo-322.github.io/V1-MT-Workshop/?host
- Critiques, votes and host actions go to the team Google Form; the site reads them back from the published Sheet (CSV) every 20 seconds on the Top critiques page.

Single self-contained `index.html`: no build step.
